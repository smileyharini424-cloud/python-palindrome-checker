# Palindrome Checker

## Explanation

This program checks whether a given input reads the same forward and backward.

## Problem Statement

Write a Python program to determine whether the entered string or number is a palindrome.

## Features

* Checks strings and numbers
* Ignores letter case
* Simple input handling
* Displays the result clearly

## How It Works

1. Accept input from the user.
2. Reverse the input.
3. Compare the original and reversed values.
4. Display whether it is a palindrome.

## Technologies Used

* Python
* Strings
* Functions
* Conditional Statements

## Data Structure Used

## Methods Used

* `is_palindrome()`
* `main()`

## Sample Input

```text
Enter a word or number: madam
```

## Sample Output
